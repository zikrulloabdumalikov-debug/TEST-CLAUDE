# 1024 o'yini

2048 uslubidagi o'yin. Maqsad — 4×4 maydonda plitkalarni birlashtirib **1024** ga yetkazish.

## Ishga tushirish

`index.html` faylini brauzerda oching. Hech qanday o'rnatish yoki server kerak emas.

## Boshqaruv

- **Klaviatura:** strelkalar yoki `W` `A` `S` `D`
- **Telefon / planshet:** barmoq bilan suring (swipe)

## Qoidalar

- Har yurishda barcha plitkalar tanlangan tomonga suriladi.
- Bir xil qiymatdagi ikki plitka to'qnashsa, ular birlashib ikki barobar qiymat beradi.
- Har yurishdan keyin maydonga 2 yoki 4 qiymatli yangi plitka tushadi.
- 1024 ga yetganingizda tabriklash oynasi chiqadi — davom etishingiz mumkin.
- Harakat qilib bo'lmasa, o'yin tugaydi.

Eng yaxshi natija brauzerda (`localStorage`) saqlanadi.
